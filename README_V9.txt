ANGELITO SHOP — AURORA V9

Versión enfocada en una experiencia responsive y touch-first.

Novedades:
- Responsive real para teléfonos, tablets y escritorio.
- Carrusel de perfumes con transición 3D visual, autoplay y gesto de deslizamiento.
- Visor de producto con efecto 2.5D interactivo: arrastre táctil, zoom y giro automático 360° visual.
- Música ambiente generada localmente con Web Audio; no depende de un archivo musical externo y se activa manualmente.
- Tarjetas de catálogo con proporciones consistentes y acciones visibles.
- Animaciones de entrada, hover, profundidad, brillo y microinteracciones.
- Respeto de prefers-reduced-motion.
- Uso de las imágenes del catálogo PDF ya integradas en la versión anterior.

Nota: el visor 360° es un efecto 2.5D basado en la imagen disponible del producto; no es un modelo 3D fotogramétrico. Para un 3D real por producto se necesitarían modelos o múltiples vistas del mismo producto.
